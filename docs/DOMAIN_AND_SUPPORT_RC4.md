# Domain & support plan — RC4

Ensisijainen domain: sanaristeys.fi.

Domainin saatavuus on vahvistettava Traficomin virallisesta fi-verkkotunnushaun käyttöliittymästä tai verkkotunnusvälittäjän hausta. DNS- tai hakukoneosumien puuttuminen ei yksin todista domainia vapaaksi.

Kun domain on rekisteröity:
- kytke DNS hostingiin
- luo erillinen tukiosoite, suositus tuki@sanaristeys.fi
- aseta osoite app-config.js -> supportEmail
- Asetusten Anna palautetta -linkki aktivoituu automaattisesti

Henkilökohtaista sähköpostiosoitetta ei tarvitse julkaista.
