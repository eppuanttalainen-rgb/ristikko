# Sanaristeys v0.8.1 RC2

RC2 lukitsee uuden julkaisunimen **Sanaristeys – suomalaiset ristikot**.

Etusivulle lisättiin pieni yhden tekijän projektista kertova kortti. Painikkeesta avautuu Tekijän sana -modal, jossa kerrotaan jatkuvasta kehityksestä sekä tavoitteesta säilyttää vanhojen suomalaisten ristikoiden rauhallinen ja oivaltava tunnelma.

Ristikkosisältöä ei muutettu. Content baseline on edelleen v0.7.6 READY / 101 ristikkoa.

Tallennus:
- uudet avaimet käyttävät Sanaristeys-nimeä
- vanhat RC1-avaimet luetaan ensimmäisellä käynnistyksellä ja migroidaan, joten eteneminen ei katoa

Seuraava portti:
- Android Chrome quick regression RC2
- Desktop Chrome quick regression RC2
- Safari HTTPS-hostatusta WEB RC2:sta
